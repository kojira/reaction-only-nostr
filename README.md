# Reaction Only

Nostrのリアクションのみで会話する実験的な静的Webクライアント。GoをWebAssemblyにコンパイルし、ブラウザ上で動作します。

NIP-07対応ブラウザ拡張でログインすると、フォロー中の人のリアクションを表示します。フィードの各リアクションから通常絵文字や登録済みカスタム絵文字を送信できます。NIP-25 kind 7を使用し、NIP-30カスタム絵文字は `:shortcode:` と `emoji` タグで表現します。秘密鍵は拡張機能が管理します。

リレー接続先は `wss://r.kojira.io`、`wss://x.kojira.io`、`wss://n.kojira.io` の3つに固定されています。これらの公開リレーに送信され、誰でも読めます。受信イベントはIDと署名を検証しますが、リレーの配信内容や完全性は保証されません。画像URLは第三者サーバーに接続します。公開リレーの受理・保持は保証されません。リレー認証、npub/nevent、削除、スレッド整理は未対応です。

## ローカルビルド

Go 1.25以降を使用し、`GOOS=js GOARCH=wasm go build -o app.wasm .` と `cp "$(go env GOROOT)/lib/wasm/wasm_exec.js" .` を実行し、HTTPサーバーで配信してください。GitHub Actionsは同じ処理を実行してPagesへデプロイします。

## 文字からカスタム絵文字を作る

文字を透過PNGに描画して blossom.primal.net にアップロードします。AIによる画像生成ではなく、文字のレンダリングです。BUD-11 kind 24242認可イベントをNIP-07で署名し、BUD-02 PUTで公開します。サーバー運営者のポリシー、容量制限、削除、CORSに依存し永続性は保証されません。画像は公開されます。

ショートコードを指定して「絵文字セットに登録」を押すと、NIP-51 kind 30030、d=reaction-only の公開セットを署名しリレーに送信します。ログイン時に接続中のリレーから取得し、ボタンで再利用できます。他の端末で更新した場合やリレーが未同期の場合、古いセットで上書きされる危険があります。セットは公開情報です。

署名検証は作者の意図や絵文字画像の安全性を保証しません。外部画像に注意してください。

リアクションは新しい会話からツリー表示します。子は親の下に表示し、未取得の親と循環は明示します。各ノードから通常絵文字または登録済みカスタム絵文字を送れます。
